## Implementation direction

The site should add accurate, human-readable Burmese/English descriptive text and structured metadata for Yangon TV’s own catalog and editorial pages. It must not add invisible keywords, fake competitor claims, or competitor-brand keyword blocks. `Bioscope`, `HomieTV`, `Channel Myanmar`, `MSub Movie`, `Mya Mya`, and `HD` may be mentioned only in genuinely useful editorial guidance or a transparent comparison page when the content is accurate and legally appropriate.

## Source notes

Google’s sitemap documentation says sitemaps should use fully qualified absolute URLs and that sitemap submission is a hint, not an indexing guarantee. It also recommends submitting via Search Console to observe processing errors. Google’s spam guidance prohibits manipulative practices such as keyword stuffing and hidden text. These principles guide the Yangon TV implementation.
