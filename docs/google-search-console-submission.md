# Yangon TV — Google Search Console Follow-up

The website now exposes crawlable public pages, a dynamic sitemap, Burmese-language homepage/catalog/Blog metadata, and canonical URLs. Google must still discover, crawl, and evaluate those pages over time. Sitemap submission is a discovery signal, **not** a guarantee of ranking or immediate indexing.[1]

## One-time setup

Open [Google Search Console](https://search.google.com/search-console/about) using the Google account that controls the Yangon TV domain. Add the exact production property:

```text
https://ygntv.vercel.app/
```

Use a supported verification method offered by Search Console. For a Vercel-hosted site, the easiest method is usually the HTML meta tag method or the HTML file method. Add only the verification token generated by Google; do not expose account passwords, API keys, or unrelated credentials.

After verification, open **Sitemaps** and submit:

```text
https://ygntv.vercel.app/sitemap.xml
```

Google’s documentation recommends absolute URLs in sitemaps and states that the Search Console report exposes processing errors and sitemap access history.[1]

## After publishing a real Blog article

Publish the article through the Admin Bot, then open its canonical URL:

```text
https://ygntv.vercel.app/blog/{post-id}-{published-year}/{title-slug}
```

Use **URL inspection** in Search Console, test the live URL, and request indexing if Google has not yet crawled the article. Check that the article title, Burmese description, canonical URL, cover image, and visible body content match what was actually published.

## Keyword approach

The current production pages naturally target Yangon TV’s genuine subject matter: **မြန်မာစာတန်းထိုး**, **ရုပ်ရှင်ဇာတ်ကားများ**, movies, series, reviews, and entertainment stories. Continue this pattern by publishing useful, specific titles and short Burmese excerpts. For example, a real review should identify the title, genre, year, viewing context, and why it is worth reading.

Do not create hidden keyword blocks or claim to be another service. Google classifies keyword stuffing, hidden text, deceptive redirects, and similar manipulative techniques as spam-policy violations.[2] Names such as Bioscope, HomieTV, Channel Myanmar, MSub Movie, Mya Mya, and HD should appear only when an article genuinely discusses them, such as an accurate comparison or industry news item. They should not be inserted just to attract searches.

## What to monitor

During the following weeks, review the **Pages**, **Sitemaps**, and **Performance** reports. Track impressions and queries for `Yangon TV`, `မြန်မာစာတန်းထိုး`, `ရုပ်ရှင်ဇာတ်ကားများ`, and the real titles of published movies or Blog posts. If a valid page is excluded, use its inspection report before changing code; the report identifies whether the problem is crawling, canonicalization, or indexability.
